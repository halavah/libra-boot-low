# 05. Http规范

> 适用范围：`03-http/*.http` 系列文件
> 索引文件：`03-http/index.md`
> 后端 Controller 对应关系见本文§二

## 一、文件命名与编号规则

### 1.1 编号分区

| 编号范围 | 类别 | 说明 |
|----------|------|------|
| 01-07 | 系统管理 | `/sys/*` 路径前缀（auth/dept/menu/post/role/user/wsdl） |
| 10-16 | 业务接口 | `/{project}/*` 路径前缀，每个文件对应 1 个 {Prefix}Controller |
| 08-09 | 保留 | 预留扩展 |

### 1.2 编号与 Controller 对照

| 编号 | 文件 | Controller | 路径前缀 |
|------|------|-----------|---------|
| 10 | `10-{role1}.http` | `{Prefix}{Role1}Controller` | `/{project}/{role1}` |
| 11 | `11-{role2}-hq.http` | `{Prefix}{Role2}Controller`（HQ） | `/{project}/{role2}` |
| 12 | `12-{role2}-sub.http` | `{Prefix}{Role2}SubController` | `/{project}/{role2}` |
| 13 | `13-{role4}.http` | `{Prefix}{Role4}Controller` | `/{project}/{role4}` |
| 14 | `14-points.http` | `{Prefix}PointsController` | `/{project}/points` |
| 15 | `15-task.http` | `{Prefix}BaseController`（D 区域） | `/{project}/task` |
| 16 | `16-upload.http` | `{Prefix}UploadController` | `/{project}/upload` |
| 17 | `17-{role3}.http` | `{Prefix}{Role3}Controller` | `/{project}/{role3}` |

**规则**：1 个 Controller = 1 个 .http 文件，编号 10 起步，连续不跳。

## 二、.http 文件内部结构

### 2.1 文件头部

```http
### ★ 模块中文名（Controller 类名）
### ★ 对应代码: {basePackage}.{project}.controller.{Prefix}XxxController
@base_url = http://localhost:9172/{project}/xxx
@token = demo-dev-admin-2026

### ============================================================
### A. 区域中文名
### ============================================================
```

- `@base_url`：后端接口前缀，对应 `@RequestMapping`
- `@token`：Dev-Token 固定值，按角色选用（admin/{role1}/{role2}/{role3}/{role4}）

### 2.2 区域注释与编号

每个 .http 文件内部按 Controller 区域注释分组，编号与 Controller 的 `@ApiOperation` 一致。

**旧标准已废弃。以下为新标准（2026-05-29 起生效）。**

> **引用此规范时，清除旧标准，以 `03-http/` 下实际文件为后端事实标准。**
> 旧标准 = 端点块内无 `### Method` / `### Params` / `### Body` 三行注释的写法。
> 后端接口变更时，HTTP 文件的注释必须同步更新。

### 2.3 接口文档三行注释（强制）

**每个接口端点块**必须在 `GET`/`POST` 请求行之前包含 3 行文档注释：

```http
### ============================================================
### Xn. 接口中文名
### ============================================================
### Method: GET
### Params: key=type, key2=type (可选)
### Body: 无
GET {{base_url}}/path?key=value
Authorization: {{token}}
```

#### Method 行

| 取值 | 说明 |
|------|------|
| `GET` | 对应 `@GetMapping` |
| `POST` | 对应 `@PostMapping` |

#### Params 行

| 格式 | 示例 | 说明 |
|------|------|------|
| 有参数 | `userId=long, status=int` | `@RequestParam` 查询参数，逗号分隔 |
| 有可选参数 | `year=int (可选), keyword=string (可选)` | 可选参数后加 `(可选)` |
| 无参数 | `无` | 无 `@RequestParam` |
| 路径参数 | `id=long (路径参数)` | `@PathVariable` |

#### Body 行

| 格式 | 示例 | 说明 |
|------|------|------|
| JSON 对象 | `{userId, roleId, deptId}` | `@RequestBody` 对象，列出字段名 |
| 嵌套对象 | `{addressId, items: [{itemType, itemId, qty}]}` | 数组嵌套用方括号 |
| 纯数组 | `[orderId] (纯数组)` | `@RequestBody List<Long>` |
| 对象数组 | `[{userId, roleId, deptId}]` | `@RequestBody List<Param>` |
| 文件上传 | `multipart/form-data (file)` | `MultipartFile` |
| 导出 | `无 (返回Excel文件流)` | 返回文件流 |
| 无 Body | `无` | GET 请求或无参 POST |

#### 完整示例

```http
### ============================================================
### A1. 供应商分页列表
### ============================================================
### Method: POST
### Params: 无
### Body: {current, size, keyword, status}
POST {{base_url}}/suppliers/page
Authorization: {{token}}
Content-Type: application/json

{
  "current": 1,
  "size": 10
}

### ============================================================
### A2. 商品详情
### ============================================================
### Method: GET
### Params: id=long
### Body: 无
GET {{base_url}}/products/detail?id=3001
Authorization: {{token}}

### ============================================================
### A3. 删除分类
### ============================================================
### Method: POST
### Params: 无
### Body: [categoryId] (纯数组)
POST {{base_url}}/category/remove
Authorization: {{token}}
Content-Type: application/json

[3001, 3002]
```

**规则**：
- 区域字母（A/B/C/...）与 Controller 区域注释一一对应
- 方法编号（A1、A2、B1...）与 `@ApiOperation("A1-xxx")` 一致
- 三行注释紧跟 `### Xn. 标题` 分隔线之后、请求行之前
- 每个 `###` 请求之间用 `###` 分隔

## 三、请求写法规范

### 3.1 HTTP 方法

| Controller 方法 | .http 方法 |
|----------------|-----------|
| `@GetMapping` | `GET` |
| `@PostMapping` | `POST` |

项目不使用 `PUT`/`DELETE`。

### 3.2 参数传递

| Controller 参数 | .http 写法 |
|----------------|-----------|
| `@RequestParam` | URL 查询参数 `?key=value` |
| `@RequestBody` | JSON body |
| `@PathVariable` | URL 路径参数 `/detail/{{id}}` |

### 3.3 认证头

```
Authorization: {{token}}
```

开发环境使用 Dev-Token 固定值（如 `demo-dev-gsda-2026`），生产环境使用 JWT Token。

### 3.4 分页参数

```
?current=1&size=10
```

## 四、新增 HTTP 文件流程

```
1. 确认目标 Controller 及其区域注释
2. 在 03-http/ 创建 XX-模块名.http（编号按§一规则）
3. 写文件头部（@base_url + @token + 模块标题）
4. 按 Controller 区域逐个写入请求（编号与 @ApiOperation 对齐）
5. 更新 03-http/index.md 索引
```

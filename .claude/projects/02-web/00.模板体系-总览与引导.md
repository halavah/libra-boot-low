# 模板体系 · 总览与引导

> 状态：现行 ｜ 版本：v1.2.0 ｜ 2026-11-09 建档

**TL;DR**：模板体系＝12 个模式目录（`templates/{mode}/`），每目录内按六段编号组织（00-inbox ~ 05-web），总计 667 个 Jinja2 模板（.j2）。模板是纯展示层——零类型判断、零字符串转换，全部预处理在 Python 侧完成。

## 当前状态

- 667 个 .j2 模板文件，分布在 12 个模式目录
- 每模式均有 README.md（模板使用说明）
- `_runtime/` 子目录为可选双模运行件（config 未开 include_runtime 时默认不渲染）
- 网关前缀 `/layer/v1/sys-service` 硬编码在前端 service 模板中

## 核心设计点表

| 设计点 | 一句话 |
|---|---|
| 纯展示层 | 模板零类型判断零转换，只引用 FieldDefinition 的现成属性 |
| 六段编号 | 00-inbox / 01-design / 02-sql(+scripts) / 03-http(+scripts) / 04-server(+page-scripts) / 05-web |
| 12 模式正交 | 业务拓扑 6 级 × 附件 2 维 |
| _runtime 可选 | 双模运行件按 config 开关渲染 |
| 网关前缀 | 前端 API 路径必须携带 `/layer/v1/sys-service` |

# 多平级系模板

> 状态：现行 ｜ 2026-11-09 建档

**TL;DR**：多平级＝主表带一个或多个**平级关联表**（字典表 / 配置表），不是主从（一对多）而是多对一或一对一关系。前端不需要子表区域，只需在主表表单中引用关联表数据。`multi-table` 45 个模板，`multi-table-with-file` 49 个。

## 一、与主从系的区别

| 维度 | master-detail | multi-table |
|---|---|---|
| 关系 | 一对多（主表→子表） | 多对一（主表→字典表） |
| 子表形态 | 业务数据（可增删改） | 字典/配置数据（通常预置） |
| 前端 | 主表下方子表区域 | 主表表单中下拉选择关联数据 |
| 典型场景 | 订单→订单明细 | 商品→商品分类（字典） |

## 二、YAML 配置结构

```yaml
modules:
  - name: "商品管理"
    code: "product"
    domain: "demo"
    mode: "multi-table"
    fields:
      - { name: "product_name", label: "商品名", type: "input", required: true }
      - { name: "category_id", label: "分类", type: "select" }
      - { name: "brand_id", label: "品牌", type: "select" }
      - { name: "price", label: "价格", type: "decimal" }
    ref_tables:                    # 关联表声明
      - table: "sys_category"
        key: "id"
        label: "category_name"
      - table: "sys_brand"
        key: "id"
        label: "brand_name"
```

## 三、生成产物

多平级系产物结构与 single 基本一致（六段），区别在后端多出关联查询：

| 产物 | 差异 |
|---|---|
| Controller | list/detail 接口返回数据附带关联表名称字段 |
| Service | 查询后 JOIN 或批量查关联表填充名称 |
| Mapper XML | SELECT 中 LEFT JOIN 关联表 |
| Vue index.vue | 表格列显示关联表名称（而非 ID） |
| Vue 表单弹窗 | select 下拉选项从关联表加载 |

## 四、gen_multi_table.py 特有逻辑

`gen_multi_table.py`（264 行）比 `gen_single.py`（90 行）多的核心逻辑：

```python
# 关联表上下文
ref_tables = module.get('ref_tables', [])
context['ref_tables'] = ref_tables

# 前端 service 需加载关联表选项
context['need_ref_load'] = len(ref_tables) > 0
```

另外 `gen_multi_table.py` 有独立的 `views_output_dir.mkdir` 调用（DRY_RUN 守卫覆盖）。

# 单表系模板

> 状态：现行 ｜ 2026-11-09 建档

**TL;DR**：单表系＝最简模式，一个 YAML 模块声明一张业务表的字段，生成完整 CRUD（6 个接口：list / detail / add / update / remove / export）。`single` 44 个模板，`single-with-file` 48 个（多附件上传 4 个模板）。

## 一、single（无附件）

### 模板分布

| 段 | 模板数 | 产物 |
|---|---|---|
| 00-inbox | 1 | .gitkeep |
| 01-design | 3 | api.md / database.md / ui.md |
| 02-sql | 3 | {code}_exec.sql / {code}_mock.sql / {code}_enum.md |
| 02-sql-scripts | 4 | run_mock.sh / .py / .ps1 / .md |
| 03-http | 1 | {code}.http |
| 03-http-scripts | 8 | test_mock 系列 |
| 04-page-scripts | 8 | run_page_test 系列 |
| 04-server | 13 | controller(1) / entity(4: param/po/vo/batch) / mapper(2: iface+xml) / service(2: iface+impl) / package-info |
| 05-web | 4 | views(1: index.vue) / service(1: api.js) / model(1) / index(1) |
| 根 | 1 | AGENT.md |

### 上下文变量（gen_single.py 组装）

```python
context = {
    'module': module,               # 含 code/domain/mode/api_path/package_path
    'fields': fields,               # List[FieldDefinition]
    'non_toggle_fields': [...],     # 排除 status_toggles 字段
    'project': project_info,        # 含 name/code/version/group
    'generated_date': 'YYYY-MM-DD',
    'has_date_field': bool,         # 控制 LocalDate import
    'has_datetime_field': bool,     # 控制 LocalDateTime import
}
```

### 生成的 6 个接口

| 接口 | 路径 | 说明 |
|---|---|---|
| list | GET /{domain}/{code}/list | 分页查询 |
| detail | GET /{domain}/{code}/detail | 单条详情 |
| add | POST /{domain}/{code}/add | 新增 |
| update | PUT /{domain}/{code}/update | 修改 |
| remove | DELETE /{domain}/{code}/remove | 删除 |
| export | GET /{domain}/{code}/export | 导出 Excel |

### 网关前缀（重要）

前端 service 文件的 API 路径**必须**携带网关路由前缀 `/layer/v1/sys-service`：

```javascript
// ✅ 正确
const SVC = '/layer/v1/sys-service'
const BASE_URL = `${SVC}/{{ module.domain }}/{{ module.code }}`

// ❌ 错误（Gateway 无法路由，返回 401）
const BASE_URL = '/{{ module.domain }}/{{ module.code }}'
```

请求链路：`浏览器 /api/layer/v1/sys-service/...` → `Vite proxy 去掉 /api` → `Gateway 匹配 /layer/v1/sys-service/**` → `StripPrefix=3 转发后端`

## 二、single-with-file（带附件）

在 single 基础上新增附件上传功能，**多 4 个模板**：

| 新增 | 产物 | 说明 |
|---|---|---|
| entity/file | Biz{Code}File.java | 附件关联实体 |
| mapper/file | {Code}FileMapper.java + xml | 附件表 CRUD |
| service/file | 附件上传/下载/删除接口 | |
| 前端附件组件 | 附件列表+上传弹窗 | |

YAML 需声明 `has_file: true` 或选择模式 `single-with-file`。

## 三、使用示例

```bash
# 1. 写配置
cat > config/demo/item.yml << 'EOF'
project:
  name: "My Project"
  code: "demo"
  version: "1.0.0"
modules:
  - name: "商品管理"
    code: "item"
    domain: "demo"
    mode: "single"
    fields:
      - { name: "title", label: "商品名", type: "input", required: true }
      - { name: "price", label: "价格", type: "decimal" }
      - { name: "status", label: "状态", type: "select", options: [...] }
EOF

# 2. 生成
python3 generator.py config/demo/item.yml

# 3. 预览（不写盘）
python3 generator.py config/demo/item.yml --dry-run
```

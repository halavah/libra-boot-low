# 主从系模板

> 状态：现行 ｜ 2026-11-09 建档

**TL;DR**：主从系＝一个主表（如订单）带一个子表（如订单明细），一对多关系。模板通过 `master_context`＋`detail_context`＋`web_context` 三套上下文分别渲染主/子/前端模板。`master-detail` 57 个模板，`master-detail-with-file` 65 个。

## 一、YAML 配置结构

主从系配置比单表多一层 `sub_tables`：

```yaml
modules:
  - name: "订单管理"
    code: "order"
    domain: "demo"
    mode: "master-detail"
    master:
      fields:
        - { name: "order_no", label: "订单号", type: "input", required: true }
        - { name: "total_amount", label: "总金额", type: "decimal" }
    sub_tables:
      - name: "订单明细"
        code: "order_item"
        fields:
          - { name: "product_name", label: "商品名", type: "input" }
          - { name: "quantity", label: "数量", type: "number" }
          - { name: "unit_price", label: "单价", type: "decimal" }
```

## 二、三套上下文

`gen_master_detail.py` 组装三套上下文分别渲染：

```
master_context = {
    'module': 主表配置（enrich 后含 api_path 等）,
    'fields': 主表字段 List[FieldDefinition],
    'project': 项目信息,
}
detail_context = {
    'module': 子表配置,
    'fields': 子表字段,
    'project': 项目信息,
}
web_context = {
    **master_context,              ← 展开（project 可达）
    'module': 合并后的模块级属性,
    'sub_tables': [子表配置列表],
    'master_fields': 主表字段,
}
```

## 三、模板渲染分流

主从系使用 `render_all_with_prefix()` 按前缀分流：

| 前缀 | 渲染上下文 | 产物目录 |
|---|---|---|
| `master/` 前缀模板 | master_context | controller/entity/mapper/service（主表） |
| `detail/` 前缀模板 | detail_context | controller/entity/mapper/service（子表） |
| `05-web/` 前端模板 | web_context | views/service（含子表组件） |

## 四、主从系 4 式对比

| 模式 | 模板数 | 子表形态 | 特点 |
|---|---|---|---|
| master-detail | 57 | 单个子表 | 基础一对多 |
| master-detail-with-file | 65 | 单个子表＋附件 | 最厚（附件×主子双面） |
| master-detail-modules | 56 | 子表独立成模块 | 子表有自己的 API 路径 |
| master-detail-modules-with-file | 64 | 独立模块＋附件 | |

### modules 与非 modules 差异

- **非 modules**：子表与主表共享同一 Controller 路径（`/{domain}/{code}/`），子表操作通过主表接口透传
- **modules**：子表有自己的独立路径（`/{domain}/{sub_code}/`），可独立 CRUD

## 五、生成产物关键文件

```
out/{domain}/{code}/
├── 02-sql/
│   ├── {code}_exec.sql              ← 主表 DDL
│   └── {sub_code}_exec.sql          ← 子表 DDL（外键关联）
├── 04-server/
│   ├── controller/
│   │   ├── {Code}Controller.java        ← 主表
│   │   └── {SubCode}Controller.java     ← 子表（modules 模式才有独立）
│   ├── entity/po/
│   │   ├── Biz{Code}.java               ← 主表 PO
│   │   └── Biz{SubCode}.java            ← 子表 PO
│   └── mapper/
│       ├── {Code}Mapper.java + xml
│       └── {SubCode}Mapper.java + xml
└── 05-web/
    └── views/
        └── {code}/
            ├── index.vue                ← 主页面（含子表区域）
            └── components/
                └── {SubCode}Table.vue   ← 子表表格组件
```

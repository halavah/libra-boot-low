# 六段产物详解

> 状态：现行 ｜ 2026-11-09 建档

**TL;DR**：每次生成产出六段编号目录（`out/{domain}/{code}/`），从设计文档到后端前端全覆盖。每段有固定文件清单，按编号顺序即工作流顺序。

## 产物总览（以 single 模式为例）

```

├── AGENT.md                        ← 交付说明（AI 代理用）
├── .manifest.json                  ← 生成清单（generator.py 写入）

├── 00-inbox/                       ← 段零：收集箱
│   └── .gitkeep
│
```

## 各段用途详解

### 00-inbox（收集箱）

空目录＋`.gitkeep`。用途：生成后临时放置待处理的文件。**无实质产物**。

### 01-design（设计文档）

| 文件 | 内容 | 消费者 |
|---|---|---|
| api.md | 接口列表（方法/路径/参数/响应） | 后端开发 / 前端联调 |
| database.md | 表结构设计（字段/类型/索引/约束） | DBA / 后端 |
| ui.md | 页面布局与交互说明 | 前端 / UI |

### 02-sql（SQL）

| 文件 | 内容 | 执行方式 |
|---|---|---|
| {code}_exec.sql | CREATE TABLE + ALTER + INDEX | run_mock.sh 执行 |
| {code}_mock.sql | INSERT 模拟数据 | run_mock.sh --data |
| {code}_enum.md | select 字段的枚举值对照表 | 人工查阅 |

`run_mock` 脚本支持三模式：0=表结构＋数据，1=仅表结构，2=仅数据。

### 03-http（HTTP 测试）

`{code}.http` 文件遵循 VS Code REST Client 格式，包含全部 6 个接口的测试用例。可直接在 VS Code 中点击发送。

### 04-server（后端）

Spring Boot 标准 MyBatis-Plus 分层：

| 层 | 文件 | 职责 |
|---|---|---|
| Controller | {Code}Controller.java | REST 接口定义＋Swagger 注解 |
| Param | {Code}Param.java | 查询/提交参数 DTO |
| PO | Biz{Code}.java | 数据库映射实体（@TableName） |
| VO | {Code}VO.java | 响应视图对象 |
| Mapper | {Code}Mapper.java + xml | MyBatis SQL |
| Service | I{Code}Service + Impl | 业务逻辑 |

`_runtime/` 子目录为可选运行件（如动态数据源配置），config 未开 `include_runtime` 时不渲染。

### 05-web（前端）

| 文件 | 内容 |
|---|---|
| index.vue | 页面组件（Element Plus 表格＋表单＋弹窗） |
| {code}.js | API 调用（axios，含网关前缀） |
| {code}.ts | TypeScript 类型定义（可选） |

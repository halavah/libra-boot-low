# 多明细与页签系模板

> 状态：现行 ｜ 2026-11-09 建档

**TL;DR**：页签系＝一个主表带**多个**子表，前端用 Tab 页签切换展示各子表。弹窗变体在页签基础上将编辑操作放入 Dialog 弹窗。4 式：tabs（55） / tabs-with-file（63） / tabs-dialog（55） / tabs-dialog-with-file（64）。

## 一、与主从系的区别

| 维度 | master-detail | master-details-tabs |
|---|---|---|
| 子表数 | 1 个 | 多个（2~N 个） |
| 前端布局 | 主表下方嵌入子表区域 | Tab 页签切换各子表 |
| 上下文 | detail_context（单个） | sub_tables 列表（多个） |
| 模板复杂度 | 较低 | 较高（多子表循环） |

## 二、YAML 配置结构

```yaml
modules:
  - name: "项目管理"
    code: "project"
    domain: "demo"
    mode: "master-details-tabs"
    master:
      fields:
        - { name: "project_name", label: "项目名", type: "input", required: true }
    sub_tables:
      - name: "任务列表"
        code: "task"
        fields:
          - { name: "task_name", label: "任务名", type: "input" }
      - name: "里程碑"
        code: "milestone"
        fields:
          - { name: "milestone_name", label: "里程碑", type: "input" }
          - { name: "due_date", label: "截止日期", type: "date" }
```

## 三、4 式对比

| 模式 | 模板数 | 交互形态 | 适用场景 |
|---|---|---|---|
| master-details-tabs | 55 | 页签内直接编辑 | 各子表字段少、操作简单 |
| master-details-tabs-with-file | 63 | 页签＋附件上传 | 子表有文件附件 |
| master-details-tabs-dialog | 55 | 页签展示＋弹窗编辑 | 子表字段多、需独立编辑面 |
| master-details-tabs-dialog-with-file | 64 | 页签＋弹窗＋附件 | 最复杂场景 |

### tabs 与 tabs-dialog 前端差异

```
tabs（页签内直接编辑）：
┌──────────────────────────────┐
│ 主表字段区（只读展示）          │
├──────┬──────┬───────────────┤
│ 任务列表│里程碑│ [更多Tab...]    │
│──────┴──────┴───────────────│
│ [子表数据表格＋行内编辑]        │
│ [+新增] [删除] [导出]         │
└──────────────────────────────┘

tabs-dialog（页签＋弹窗编辑）：
┌──────────────────────────────┐
│ 主表字段区（只读展示）          │
├──────┬──────┬───────────────┤
│ 任务列表│里程碑│ [更多Tab...]    │
│──────┴──────┴───────────────│
│ [子表数据表格（只读）]          │
│ [+新增（弹窗）] [编辑（弹窗）]   │
└──────────────────────────────┘
点击新增/编辑 → 弹出 Dialog → 填写表单 → 确认关闭
```

## 四、生成产物关键差异

页签系比主从系多出的模板：

| 模板 | 说明 |
|---|---|
| `TabNav.vue.j2` | 页签导航组件 |
| `{SubCode}Tab.vue.j2` | 每个子表独立的 Tab 面板组件 |
| `{SubCode}Dialog.vue.j2` | 弹窗编辑组件（dialog 变体独有） |
| `{SubCode}FileTab.vue.j2` | 附件 Tab 面板（with-file 变体独有） |

## 五、子表循环渲染

页签系模板通过 Jinja2 循环处理多个子表：

```jinja
{% for sub in module.sub_tables %}
<el-tab-pane label="{{ sub.name }}" name="{{ sub.code }}">
  <{{ sub.code | pascal }}Tab
    :data="formData.{{ sub.code }}List"
    @refresh="load{{ sub.code | pascal }}List"
  />
</el-tab-pane>
{% endfor %}
```

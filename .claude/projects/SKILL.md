# projects 归档技能

## 动归档文档前先过四问

1. 属哪个目录？
2. 有无同主题旧档？
3. 更新还是新增？
4. 要不要同步 README？

一问没答清不新建文件。

## 目录判断

| 讲什么 | 放哪个目录 |
|--------|-----------|
| 系统怎么设计 | 设计目录（01-frame / 01-server / 02-web*） |
| 代码怎么写 | 代码规范目录（00-code） |
| 这次任务怎么做 | 执行目录（03-exec） |
| 阶段产出 | 报告目录（03-report） |
| 问题跟踪 | 问题目录（04-issues） |

## 命名规则

- 系列文档：`NN.四字前缀-主题.md`（前缀四字中文，不含英文）
- 独立文档：`NN.主题.md`（无前缀，编号仅排序）
- X0 = 总览与引导（禁写实质内容）
- 编号两位起，连续不跳号

## 读写纪律

- 写前必读：先 ls 找同主题，再 grep 找"标题不同主题同"的旧档
- 五类场景不新开补充文档：小变/可承载/标题不准但主题同/只想留痕/未满3篇
- 尾部双小节恒居文末：【AI 误判清单】＋【窗口重开提示词】

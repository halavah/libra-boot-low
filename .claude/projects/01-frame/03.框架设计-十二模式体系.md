# 十二模式体系

> 状态：现行 ｜ 版本：v1.2.0 ｜ 2026-11-09 建档

**TL;DR**：12 模式＝业务拓扑（4 级）× 附件维度（有无），正交组合形成完整矩阵。模板数从 44（single）到 65（master-detail-with-file），复杂度随拓扑升维递增。

## 一、模式矩阵（4 级拓扑 × 2 附件）

| 业务拓扑 | 无附件 | 有附件 |
|---|---|---|
| **单表** | single | single-with-file |
| **多平级** | multi-table | multi-table-with-file |
| **主从（一对多）** | master-detail | master-detail-with-file |
| **主从（模块化）** | master-detail-modules | master-detail-modules-with-file |
| **主多明细（页签）** | master-details-tabs | master-details-tabs-with-file |
| **主多明细（页签弹窗）** | master-details-tabs-dialog | master-details-tabs-dialog-with-file |

## 二、每模式产物规模

| 模式 | 模板数 | gen 件行数 | 说明 |
|---|---|---|---|
| single | 44 | 90 | 单表 CRUD，6 个接口 |
| single-with-file | 48 | 91 | 单表＋附件上传 |
| multi-table | 45 | 264 | 主表＋字典/配置表关联 |
| multi-table-with-file | 49 | 274 | 多表＋附件 |
| master-detail | 57 | 314 | 主子表一对多 |
| master-detail-with-file | 65 | 391 | 主子表＋附件（最厚） |
| master-detail-modules | 56 | 382 | 主子表（子表独立成模块） |
| master-detail-modules-with-file | 64 | 428 | 模块化主子＋附件 |
| master-details-tabs | 55 | 403 | 一主多子页签切换 |
| master-details-tabs-with-file | 63 | 414 | 页签＋附件 |
| master-details-tabs-dialog | 55 | 413 | 页签＋弹窗编辑 |
| master-details-tabs-dialog-with-file | 64 | 414 | 页签弹窗＋附件 |

## 三、模式分发的三组列表

`generator.py` 用三个列表将模式路由到对应 gen 件：

```python
SINGLE_MODES = ['single', 'single-with-file']
MASTER_DETAIL_MODES = [
    'master-detail', 'master-detail-with-file',
    'master-detail-modules', 'master-detail-modules-with-file',
    'master-details-tabs', 'master-details-tabs-with-file',
    'master-details-tabs-dialog', 'master-details-tabs-dialog-with-file',
]
MULTI_TABLE_MODES = ['multi-table', 'multi-table-with-file']
```

分发逻辑（`Generator.generate()` 内）：遍历模块，按 `module['mode']` 值匹配上述列表，调用对应 `generate()` 函数。

## 四、主从系的核心差异

主从系模板与单表系最大区别：**一个模块的上下文包含主表和子表两套字段列表**。

```
master-detail 模式上下文：
├── master_context = {
│     'module': 主表配置,
│     'fields': 主表字段列表,
│     'project': 项目信息,
│ }
├── detail_context = {
│     'module': 子表配置,
│     'fields': 子表字段列表,
│     'project': 项目信息,
│ }
└── web_context = {
      **master_context,           ← 展开继承 project
      'module': 合并后的模块级属性,
      'sub_tables': [子表配置列表],
}
```

主从系使用 `render_all_with_prefix()` 而非 `render_all()`，以区分主表和子表模板的前缀。

## 五、六段产物编号体系

每个模式生成产物按编号组织：

| 段 | 目录 | 内容 |
|---|---|---|
| 00 | 00-inbox | 生成物清单 |
| 01 | 01-design | 设计文档（api.md / database.md / ui.md） |
| 02 | 02-sql | 建表 DDL（*_exec.sql / *_mock.sql / *_enum.md） |
| 02 | 02-sql-scripts | SQL 执行脚本（run_mock.sh / .py / .ps1 / .md） |
| 03 | 03-http | HTTP 接口测试用例（*.http） |
| 03 | 03-http-scripts | HTTP 测试运行脚本 |
| 04 | 04-server | Spring Boot 后端（controller / entity / mapper / service） |
| 04 | 04-page-scripts | 页面测试脚本 |
| 05 | 05-web | Vue3 前端（views / service） |

`_runtime/` 双模运行件：04-server 下的可选子目录，config 未开 `include_runtime` 时默认不渲染。

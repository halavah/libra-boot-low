# 框架设计 · 总览与引导

> 状态：现行 ｜ 版本：v1.2.0 ｜ 2026-11-09 建档

**TL;DR**：libra-boot-low 是一个 Python 低代码生成器——用 YAML 声明业务字段，经 Jinja2 模板渲染，一键生成 Spring Boot + Vue3 全栈骨架（后端/前端/SQL/HTTP 测试全链路）。本系列共 7 篇，覆盖架构→类型→模式→配置→质量五个维度。

## 全景树形图

```
libra-boot-low/
├── generator.py            ← 唯一入口（CLI→分发→报告）
├── module/
│   ├── config_loader.py    ← 配置加载与校验
│   ├── field_builder.py    ← 字段类型转换器
│   ├── template_renderer.py← Jinja2 渲染引擎
│   ├── gen_single.py       ← 模式生成器×14
│   │   └── ...
│   └── master_detail_utils.py ← 主从公共工具
├── templates/              ← 12 模式 × 六段产物
│   ├── single/             （44 个模板文件）
│   └── ...共 12 目录
├── config/test/            ← 24 个 YAML 测试配置
├── tests/                  ← pytest 12 用例
└── .github/workflows/      ← CI＋PyPI 双工作流
```

- 版本 v1.2.0 已上架 PyPI（`pip install libra-boot-low`）

## 核心设计点表

| 设计点 | 一句话 |
|---|---|
| 四层架构 | 入口→公共（加载/转换/渲染）→模式→模板→配置 |
| DRY_RUN | 模块级旗标守五处写点，预览零落盘 |
| StrictUndefined | 模板引用未定义变量直接报错，防哑生成 |
| 十二模式 | 业务拓扑（单表→主从→页签→弹窗）× 附件维度 |
| 六段产物 | 00-inbox/01-design/02-sql/03-http/04-server/05-web |
| TYPE_MAPPING | 一张字典驱动 Java/SQL/Vue/MyBatis 四端类型 |
| project.group | 可配置包前缀，默认 com.libra，全模板引用 |
| Trusted Publishing | 推 v* 标签→Actions 自动构建→OIDC 免密发布 |

# 配置与验证

> 状态：现行 ｜ 版本：v1.2.0 ｜ 2026-11-09 建档

**TL;DR**：配置＝一个 YAML 文件声明项目＋模块＋字段。ConfigLoader 采用加载/校验分离设计（`--validate` 只校验不生成）。`project.group` 为可配置包前缀（默认 `com.libra`），模板侧通过 `{{ project.group }}` 引用。

## 一、YAML 配置结构

```yaml
# 最小配置（t1000.yml 精简版）
project:
  name: "Libra Boot Low"      # 项目名
  code: "demo"                 # 项目编码（英文小写）
  version: "1.0.0"             # 项目版本
  group: "com.libra"           # 包前缀（可选，默认 com.libra）

modules:
  - name: "单表无附件"          # 模块中文名
    code: "t1000"              # 模块编码（英文小写）
    domain: "test"             # 业务域编码
    mode: "single"             # 生成模式（12 种之一）
    description: "T01 测试模块"

    fields:                    # 字段列表
      - name: "title"
        label: "标题"
        type: "input"          # 类型（TYPE_MAPPING 10 种之一）
        required: true
        filterable: true
        show_in_list: true
      - name: "status"
        label: "状态"
        type: "select"
        options:
          - label: "启用"
            value: "1"
          - label: "禁用"
            value: "0"
      - name: "create_time"
        label: "创建时间"
        type: "datetime"

    status_toggles:             # 状态开关（可选）
      - field: "status"
        label: "状态"
        values:
          "0": "禁用"
          "1": "启用"
        colors:
          "0": "danger"
          "1": "success"
```

## 二、ConfigLoader 加载/校验分离

| 方法 | 职责 | 何时调用 |
|---|---|---|
| `load()` | 读取 YAML → dict，补 `project.group` 默认值 | 总是先调 |
| `validate()` | 校验必填字段＋模式合法性，返回 (bool, errors) | `--validate` 单独调，或 generate 前调 |
| `get_modules()` | 返回 modules 列表 | gen_*.py 调 |
| `enrich_module(module)` | 补计算字段 | gen_*.py 调 |
| `enrich_sub_table(sub)` | 补子表计算字段 | 主从系调 |
| `enrich_master_detail_submodule(sub)` | 补模块化主从子配置 | modules 系调 |

分离的好处：`--validate` 模式下只做校验不执行生成，CI 可独立使用。

### 校验规则

| 规则 | 内容 |
|---|---|
| REQUIRED_MODULE_FIELDS | `['name', 'code', 'domain', 'mode']` 四项必填 |
| VALID_MODES | 12 种模式名 |
| MASTER_DETAIL_MODES | 8 种主从系（用于区分路由） |
| 域映射 | `DOMAIN_CHINESE_MAP = {'demo': '示例业务域', 'test': '测试验证域'}` |

## 三、project.group 可配置包前缀

**v1.2.0 新增**。模板中所有 Java 包名均通过 `{{ project.group }}` 引用：

```java
// 模板写法
package {{ project.group }}.layer.bis.{{ module.domain }}.{{ module.code }}.controller;

// project.group = "com.libra" 时输出
package com.libra.layer.bis.test.t1000.controller;

// project.group = "com.yourcompany" 时输出
package com.yourcompany.layer.bis.test.t1000.controller;
```

**注入逻辑**：`ConfigLoader.load()` 在读取后检查 `project.group`，为空时自动注入默认值 `'com.libra'`。24 个测试配置均未显式声明 group，全部走默认值。

## 四、ConfigIndexer 索引器

`generator.py` 中的 `ConfigIndexer` 负责扫描 `config/*/` 下所有 `.yml` 文件，生成 `config/index.json` 索引。`run.sh` 交互菜单依赖此索引提供域和模块列表。

```bash
python generator.py -u              # 重建索引
python generator.py --update-index  # 同上
```

索引内容：每个配置的 domain / code / file 路径（仅相对路径）。

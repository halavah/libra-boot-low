# 类型映射与字段构建

> 状态：现行 ｜ 版本：v1.2.0 ｜ 2026-11-09 建档

**TL;DR**：字段类型系统＝一张字典（TYPE_MAPPING）＋一个数据类（FieldDefinition）。YAML 声明 `type: input`，Python 侧自动映射为 Java `String`＋SQL `VARCHAR(200)`＋Vue `el-input`＋MyBatis `VARCHAR`。新增一种类型只需在表里加一行，667 个模板自动适配。

## 一、TYPE_MAPPING 全表（10 类型）

| YAML type | Java 类型 | SQL 类型 | SQL 长度 | Vue 组件 | MyBatis JdbcType |
|---|---|---|---|---|---|
| `input` | String | VARCHAR | 200 | el-input | VARCHAR |
| `textarea` | String | TEXT | — | el-input[type=textarea] | LONGVARCHAR |
| `number` | Integer | INT | — | el-input-number | INTEGER |
| `decimal` | BigDecimal | DECIMAL | — | el-input-number | DECIMAL |
| `date` | LocalDate | DATE | — | el-date-picker | DATE |
| `datetime` | LocalDateTime | DATETIME | — | el-date-picker | TIMESTAMP |
| `date-year` | Integer | INT | — | el-date-picker | INTEGER |
| `date-month` | String | VARCHAR | 10 | el-date-picker | VARCHAR |
| `select` | Integer | INT | — | el-select | INTEGER |
| `upload` | String | VARCHAR | 500 | custom-upload | VARCHAR |

**新增一种类型**：在 `field_builder.py` 的 `TYPE_MAPPING` 字典追加一行即可，无需改任何模板或其他代码。

## 二、FieldDefinition 数据类（24 字段）

`build()` 方法将 YAML 原始 dict 转为扁平化 dataclass，模板直接用 `{{ field.java_type }}` 引用，无需在模板内做任何类型判断或字符串转换。

### 输入字段（来自 YAML）

| 字段 | 类型 | 说明 |
|---|---|---|
| name | str | 字段名（snake_case） |
| label | str | 中文标签 |
| type | str | YAML 类型（上表 10 种之一） |
| required | bool | 是否必填 |
| filterable | bool | 是否可筛选 |
| show_in_list | bool | 是否在列表页显示 |
| indexed | bool | 是否建索引 |
| generated | bool | 是否为自动生成字段 |
| options | list | select 类型的选项列表 |
| default | Any | 默认值 |
| placeholder | str | 输入提示 |
| maxlength | int | 最大长度 |

### 计算字段（Python 侧推导）

| 字段 | 类型 | 推导规则 |
|---|---|---|
| java_type | str | 从 TYPE_MAPPING 查 |
| sql_type | str | 从 TYPE_MAPPING 查 |
| sql_length | str | 从 TYPE_MAPPING 查 |
| vue_component | str | 从 TYPE_MAPPING 查 |
| mybatis_jdbc_type | str | 从 TYPE_MAPPING 查 |
| column_name | str | = name（snake_case） |
| name_pascal | str | snake→PascalCase（如 `create_time` → `CreateTime`） |
| name_camel | str | snake→camelCase（如 `create_time` → `createTime`） |
| default_value | Any | 类型感知的默认值 |
| vue_filter_type | str | Vue 表格筛选组件类型 |
| vue_display | str | Vue 展示格式化 |
| options_json | str | select 选项的 JSON 序列化 |

### 转换示例

```yaml
# YAML 输入
- name: create_time
  label: 创建时间
  type: datetime
  required: true
```

```python
# Python 侧 build() 输出
FieldDefinition(
    name='create_time',
    label='创建时间',
    type='datetime',
    required=True,
    java_type='LocalDateTime',
    sql_type='DATETIME',
    vue_component='el-date-picker',
    mybatis_jdbc_type='TIMESTAMP',
    column_name='create_time',
    name_pascal='CreateTime',
    name_camel='createTime',
    ...
)
```

```jinja
{# Jinja2 模板直接引用 #}
private {{ field.java_type }} {{ field.name_camel }};  {# → private LocalDateTime createTime; #}
```

## 三、status_toggles 自动补列

当 YAML 配置了 `status_toggles` 但未在 `fields` 中声明对应字段时，`ensure_status_fields()` 自动补充为 select 类型的 Integer 字段，使 DDL / Mapper / VO / Param 模板能正确渲染这些列。PO 模板已有 toggle_fields 排除逻辑，不会重复渲染。

```yaml
# YAML 声明
status_toggles:
  - field: "status"
    label: "状态"
    values:
      "0": "禁用"
      "1": "启用"
```

如果 `fields` 中没有 `status` 字段，`ensure_status_fields` 会自动创建一个 `select` 类型的字段并填入上述选项。

## 四、批量转换入口

| 方法 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `build(field_dict)` | 单个字段 dict | FieldDefinition | 核心转换 |
| `build_fields(field_list)` | List[dict] | List[FieldDefinition] | 批量转换 |
| `ensure_status_fields(fields, toggles)` | List + List | List | 补缺失的 toggle 字段 |
| `get_java_field(field)` | FieldDefinition | str | 生成 Java 字段声明 |
| `get_sql_column(field)` | FieldDefinition | str | 生成 SQL 列定义 |
| `get_vue_form_item(field)` | FieldDefinition | str | 生成 Vue 表单项（扩展备用，主流程未调用） |

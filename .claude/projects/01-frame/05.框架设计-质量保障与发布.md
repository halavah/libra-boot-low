# 质量保障与发布

> 状态：现行 ｜ 版本：v1.2.0 ｜ 2026-11-09 建档

**TL;DR**：三层质量网——pytest 12 用例（本地）→ CI 三矩阵 3.9/3.11/3.13（推送触发）→ Trusted Publishing OIDC（标签触发自动发布 PyPI）。推 v* 标签即全自动：测试→构建→免密上架。

## 一、pytest 测试体系（12 用例）

| 测试文件 | 用例数 | 覆盖内容 |
|---|---|---|
| `test_config_loader.py` | 5 | 模式表 12 种、加载/校验 t1000、enrich 字段、域映射、非法模式拒绝 |
| `test_field_builder.py` | 3 | input→String/VARCHAR 映射、select→el-select、name 三形态转换 |
| `test_dry_run.py` | 1 | 子进程级：dry-run 后 out/output 目录不存在 |
| `test_renderer.py` | 1 | StrictUndefined 模式：未定义变量抛 UndefinedError |
| `test_gen_single.py` | 1 | 真渲染：六段目录齐全＋.sql/.http 文件存在 |

```bash
# 本地运行
pip install pytest pyyaml jinja2
python -m pytest tests/ -q     # 12 passed
```

## 二、CI 工作流（.github/workflows/ci.yml）

推送 master 触发，Python 3.9/3.11/3.13 三矩阵并行：

| 步骤 | 内容 | 耗时 |
|---|---|---|
| 语法检查 | py_compile generator.py + module/*.py | ~2s |
| CLI 冒烟 | --version / --list-modes / -h | ~3s |
| 单元测试 | python -m pytest tests/ -q | ~10s |
| 全量 dry-run 回归 | 24 配置零落盘断言（步内自清场） | ~10s |
| 渲染矩阵 | 24 配置全量渲染＋SB3 合规扫（javax/swagger 归零门） | ~15s |
| 产物断言 | t1000/t5000 渲染后 .java/.vue/.sql/.http 文件存在 | ~5s |

**自清场机制**：dry-run 步骤开头 `rm -rf output ../../out`，隔离前序步骤（渲染矩阵）的产物污染零落盘断言。

## 三、PyPI 发布工作流（.github/workflows/pypi.yml）

推送 `v*` 标签触发：

```
标签推送 → Checkout（需 contents:read 权限）
        → Setup Python 3.11
        → 安装依赖（pyyaml jinja2 pytest build）
        → 运行 pytest 12 用例（发布前质量闸）
        → python -m build（构建 wheel + sdist）
        → pypa/gh-action-pypi-publish（OIDC 免密发布）
```

**关键权限配置**：

```yaml
permissions:
  contents: read    # 私有仓 checkout 必需（permissions 块会覆盖隐式默认）
  id-token: write   # OIDC 必需
```

**坑**：`permissions` 块指定 `id-token: write` 时会**覆盖隐式默认**，导致 `contents` 权限丢失。私有仓必须显式加 `contents: read`，否则 checkout 报 `repository not found`。公开仓因匿名克隆掩盖了此问题。

## 四、Trusted Publishing 免密发布

在 pypi.org 的 Publishing 配置页一次性绑定：

| 配置项 | 值 |
|---|---|
| PyPI project name | libra-boot-low |
| owner | halavah |
| repository | libra-boot-low |
| workflow | pypi.yml |
| environment | （留空） |

配置完成后，推任何 `v*` 标签 → Actions 自动构建 → OIDC 免密上传 PyPI → 项目页 README 自动刷新。

**无需任何 token 或密码**——OIDC（OpenID Connect）协议通过 GitHub Actions 的短期凭证向 PyPI 证明身份。

# Plan Creator (计划创建专家)

> **作用**: 为项目创建结构化的分阶段计划文档
> **触发词**: "制定计划"、"创建计划"、"规划"、"写个计划"

---

## 触发场景

- 用户说"制定 xxx 计划"
- 用户说"创建 xxx 项目计划"
- 用户说"规划 xxx"
- 用户说"给 xxx 写个计划"

---

## 目录规则

### 存放位置

```
.claude/plans/{项目名}/
```

### 必需文件

每个计划目录**必须**包含 `MEMORY.md` 用于追踪任务进度。

### 命名规则

**格式**: `{两位序号}-{中文标题}.md`

| 规则 | 说明 | 示例 |
|------|------|------|
| 序号 | 两位数字，01-99 | `01-`, `02-` |
| 分隔符 | 中划线 `-` | |
| 标题 | 简洁中文描述 | `需求分析`, `技术方案` |
| 扩展名 | `.md` | |

**正确示例**: `01-需求分析.md`, `02-技术选型.md`
**错误示例**: `❌ 1-需求分析.md`（序号不是两位）, `❌ 01_需求分析.md`（分隔符错误）

---

## 编号分类

| 编号范围 | 分类 | 典型文档 |
|----------|------|----------|
| **01-09** | 规划调研 | 需求分析、生态调研、可行性分析 |
| **10-19** | 架构设计 | 技术选型、架构设计、数据库设计、API设计 |
| **20-29** | 开发实施 | 实施计划、功能迁移、开发规范 |
| **30-39** | 部署运维 | 部署方案、监控告警、应急预案 |

## 检查清单

创建计划后确认：

- [ ] 文件存放在 `.claude/plans/{项目名}/` 目录
- [ ] **MEMORY.md 已创建**（必需）
- [ ] 文件名符合 `{两位序号}-{中文标题}.md` 格式
- [ ] 编号分类正确（01-09规划/10-19设计/20-29开发/30-39部署）
- [ ] 文件包含版本号和更新日期
- [ ] 内容结构清晰，分节明确
- [ ] 关键决策点已列出（如有）

## MEMORY.md 更新规则

### 何时更新

| 时机 | 操作 |
|------|------|
| 创建新计划 | 初始化 MEMORY.md，设置 Phase 1 |
| 完成任务 | 标记 ✅ 完成，更新进度表 |
| 开始新阶段 | 新增 Phase N 节，标记 ⏳ 进行中 |
| 用户确认配置 | 添加到「用户确认的配置」表 |
| 遇到阻塞 | 添加到「阻塞问题」节（如有） |

### 状态标记

| 标记 | 含义 |
|------|------|
| ✅ | 已完成 |
| ⏳ | 进行中 |
| ⏸️ | 暂停/阻塞 |
| ❌ | 取消/失败 |
